# tanedb

🌱 A small relational database written in Ruby for learning.

A from-scratch RDBMS built one piece at a time — storage, indexing, query parsing, execution — to understand how real database systems work under the hood.

## Status

Early stage. Growing from a seed.

## Roadmap

- [ ] In-memory single table with a REPL
- [ ] Page-based on-disk storage
- [ ] B-Tree index
- [ ] SQL parser (subset)
- [ ] Multiple tables and joins
- [ ] Transactions
